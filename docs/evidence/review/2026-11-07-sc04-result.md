# SC-04 certificate-expiry result — 2026-11-07

This is one local measurement, not a general TLS availability claim. The
invalid `sc04a` setup attempt remains preserved and is described in the
scenario document.

## Run and boundary

`sc04b` used the disposable `sc04-tls-proxy` Deployment and Service. The proxy
ran from the locally loaded `tawira:chaos-local` image and forwarded to the
unchanged `tawira:3000` Service. The load pod trusted only the temporary test
CA. The valid leaf was serial `1000`; the expired leaf was serial `1001`, with
`notAfter=Nov 6 09:24:08 2026 GMT`.

The runner waited for the projected Secret serial, sent `SIGHUP`, and verified
the proxy pod start time and container restart count stayed unchanged. A new
handshake then failed with `CERT_HAS_EXPIRED`. The valid serial was restored and
reloaded; the next handshake returned HTTP 200.
